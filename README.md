# Clop Codex

Настольный помощник для Windows: работает прямо на вашем компьютере — читает и пишет файлы, запускает команды, собирает проекты. Вход через Telegram, лимиты того же аккаунта, что и в боте [@clop_ai_bot](https://t.me/clop_ai_bot) и на сайте.

## Установка

Скачайте `Clop-Codex-Setup-<версия>.exe` из [релизов](../../releases) и запустите. Установщик обычный: можно выбрать папку, ярлыки создаются автоматически.

При первом запуске нажмите «Войти через Telegram» — откроется бот, подтвердите подключение, и окно само продолжит работу.

## Как это устроено

Думает сервер, действует компьютер:

1. Вы пишете задачу в окне.
2. Приложение отправляет её на сервер Clop ai вместе с вашим личным токеном.
3. Сервер проверяет лимиты вашего Telegram-аккаунта и возвращает ответ модели.
4. Если в ответе есть действие — команда, чтение или запись файла, — приложение **спрашивает вас** и только потом выполняет.
5. Результат уходит обратно модели, и цикл повторяется, пока задача не решена.

Расход идёт в тот же лимит, что и в боте: отдельных счётчиков у приложения нет.

## Настройки подтверждений

По умолчанию помощник спрашивает разрешение на каждое изменение. В настройках это можно ослабить — но только там, где ослаблять безопасно:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Читать файлы без подтверждения | включено | Просмотр папок и чтение файлов внутри рабочей папки. Ничего не меняет. |
| Создавать и менять файлы без подтверждения | выключено | Запись файлов внутри рабочей папки. Удобно, когда собирается проект из многих файлов. |
| Выполнять команды без подтверждения | выключено | Обычные команды внутри рабочей папки. |

В окне подтверждения есть третья кнопка — «Разрешать до конца сеанса»: послабление действует до закрытия приложения и на диск не сохраняется.

**Что не отключается никогда:**

- всё, что выходит за пределы выбранной рабочей папки;
- опасные команды — форматирование, рекурсивное удаление, правка реестра, выключение, работа с учётными записями, запуск скачанного скрипта через конвейер. Они спрашиваются даже при включённом автоподтверждении.

## Безопасность

Установщик может скачать кто угодно, поэтому он сделан так, чтобы из него нечего было украсть.

**В файлах приложения нет ни одного секрета.** Ни ключей от моделей, ни общего токена, ни пароля. Вскрыв `.exe`, вы не найдёте ничего, чем можно воспользоваться.

**Токен выдаётся только вам и только после подтверждения в Telegram.** При входе приложение придумывает пару: короткий код и длинный секрет. На сервер уходит код и лишь *хэш* секрета — сам секрет не покидает ваш компьютер. Код виден в ссылке на бота, но обменять его на токен без секрета нельзя. Код одноразовый и живёт 10 минут.

**Токен лежит зашифрованным.** Используется системное хранилище Windows (DPAPI через `safeStorage`), привязанное к вашей учётной записи: другой пользователь того же компьютера файл не расшифрует.

**Доступ отзывается в один клик.** Команда `/devices` в боте показывает все подключённые устройства и отключает любое — токен перестаёт приниматься сразу.

**По умолчанию ничего не выполняется без спроса.** Каждая команда и каждая запись файла показываются целиком и ждут вашего «Разрешить»; ослабить это можно в настройках, но выход за рабочую папку и опасные команды спрашиваются всегда (см. раздел выше). У команд есть таймаут 120 секунд.

**Окно изолировано от системы.** Интерфейс не имеет доступа ни к Node, ни к файлам: включены `contextIsolation` и `sandbox`, а наружу открыт только явный список вызовов. Внешние ссылки открываются в системном браузере, а не внутри приложения.

## Сборка из исходников

```bash
npm install
npm run dist
```

Готовый установщик появится в `dist/`. Иконка генерируется кодом (`npm run icon`), картинок в репозитории нет.

Для отладки:

```bash
npm start
```

Сервер по умолчанию — `https://clop-ai.onrender.com`. Свой адрес задаётся переменной `CLOP_SERVER`.
